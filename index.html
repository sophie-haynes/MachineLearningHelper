Coursework Helper

A Machine Learning project can be broken down into eight main stages. Your coursework, and this helper, is comprised of those stages. In this helper, each stage presents you with the questions you need to answer about your chosen dataset, and provides code snippets to help you apply this to your own dataset. Additionally, it explains how to interpret the output, and provides guidance on how to write it out.
